# A Practical Inverse Design Approach for High-Entropy Catalysts with Generative AI

## 1. Requirements

```bash
pip install -r requirements.txt
```

## 2. Training the Models

All scripts in this section are located in the `SpecGen` directory. Please navigate to the directory before running the commands.

The spectra-to-compositions (S2C) model uses spectroscopic descriptors to predict metal compositions.

The S2C model should be trained by the following command:

```bash
python s2c.py
```

The spectra-to-performances (S2P) model is employed to obtain the relationships between spectroscopic descriptors and measured performance.

The S2P model should be trained by the following command:

```bash
python s2p.py
```

The VAE model is employed to extract and generate spectral features from spectroscopic descriptors.

The VAE model should be trained by the following command:

```bash
python vae.py
```

## 3. Spectra Generation

All scripts in this section are located in the `SpecGen` directory. Please navigate to the directory before running the commands.

The metal compositions with the best performance should be generated by the following command:

```bash
python top_gen.py
```
